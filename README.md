# docbobo Gas City packs

Gas City packs, one directory per pack.

| Pack | What it does |
| --- | --- |
| [`ub-mode/`](ub-mode/) | Uncle Bob's ub-mode discipline: skill, quality-gate tools, build formula |

Import a pack by URL:

```toml
[imports.ub-mode]
source = "https://github.com/docbobo/gascity-packs/tree/main/ub-mode"
version = "^0.1"
```
